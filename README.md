# Sand Mandala — web

Las páginas públicas de Sand Mandala (portada, soporte y privacidad, en
español e inglés), servidas por GitHub Pages desde la raíz de `main`. HTML
y CSS estáticos, sin generador, sin scripts y sin recursos de terceros: las
tipografías (Manrope y Cormorant Garamond, SIL Open Font License) están en
`assets/fonts`, con sus licencias.

- Portada: `/` (es) y `/en/` (en)
- Soporte: `/soporte/` y `/support/`
- Privacidad: `/privacidad/` y `/privacy/`

El código de la app no está aquí.
